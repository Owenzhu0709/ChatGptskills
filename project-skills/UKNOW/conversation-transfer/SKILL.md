# UKNOW Conversation Transfer

1. Identify the destination task and include only context that helps it.
2. Extract verified facts, decisions, unresolved questions, commitments, and relevant artifacts.
3. Preserve speaker intent and source links; label summaries and inferences.
4. Remove secrets and irrelevant personal information.
5. Use the core handoff and decision-log formats when continuity or decisions are involved.
