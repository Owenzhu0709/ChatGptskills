# UKNOW Analysis

1. State the decision or question the analysis must support.
2. Inventory sources and assess freshness, reliability, gaps, and conflicts.
3. Separate observations, interpretations, assumptions, and recommendations.
4. Compare credible alternatives and explain tradeoffs.
5. End with a decision-ready conclusion, confidence level, and next evidence to collect.
