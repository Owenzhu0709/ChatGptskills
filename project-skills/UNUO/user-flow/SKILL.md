# UNUO User Flow

1. Identify actor, entry condition, intent, and success state.
2. Map the happy path, decisions, system states, errors, recovery, and exit points.
3. Show where data, consent, payment, or human intervention occurs.
4. Minimize steps while preserving trust and clarity.
5. Link each flow to its product rule and acceptance evidence.
