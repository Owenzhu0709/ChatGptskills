# UNUO Mentor System

1. Define the mentor promise and explicit service boundaries.
2. Specify eligibility, onboarding, matching inputs, availability, session lifecycle, and offboarding.
3. Design quality signals, feedback, moderation, dispute handling, and escalation.
4. Align mentor incentives with user outcomes rather than activity volume alone.
5. Flag legal, safeguarding, privacy, or professional-advice risks for specialist review.
