# GPC Dashboard

1. Identify the operating decision each view supports.
2. Define metric owner, source, formula, timezone, refresh cadence, and status thresholds.
3. Distinguish live data, snapshots, manual inputs, and derived indicators.
4. Surface exceptions, stale data, blockers, and required actions before decorative summaries.
5. Validate totals and source links before publishing.
