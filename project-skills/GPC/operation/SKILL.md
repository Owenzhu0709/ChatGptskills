# GPC Operation

1. Confirm the approved accounts, platforms, time window, and permitted actions.
2. Read the current GPC context, operating rules, and latest handoff.
3. Separate read-only checks from external writes and obtain required approval before posting, messaging, or changing account state.
4. Record action, target, result, evidence, and next owner.
5. Stop on authentication, ownership, policy, or identity ambiguity.
