# GPC Workflow

1. Define trigger, actor, inputs, permissions, states, outputs, and terminal conditions.
2. Make read-only, draft, approved-write, and completed states explicit.
3. Include authentication failures, duplicate records, conflicting messages, policy risks, and recovery paths.
4. Preserve source identifiers and audit evidence.
5. Test the workflow with a normal case and at least one failure case before adoption.
