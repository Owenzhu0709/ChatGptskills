# Decision Log

1. Confirm the decision is final enough to preserve; label proposals as proposals.
2. Append one entry using `templates/DECISION_LOG.md` when available.
3. Include date, status, decision, context, evidence, rationale, alternatives, consequences, owner, and revisit trigger.
4. Link source artifacts and avoid rewriting their full content.
5. Never silently overwrite an earlier decision. Supersede it with a new entry and reference the old one.
