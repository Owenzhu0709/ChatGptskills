# Project Handoff

1. Read `PROJECT_CONTEXT.md`, `DECISION_LOG.md`, relevant plans, repository status, and recent verification output.
2. Separate verified facts from assumptions and proposed work. Never report a plan as completed.
3. Record current state, completed work, remaining work, next action, risks, blockers, and protected constraints.
4. Link existing artifacts instead of duplicating them. Redact credentials and private identifiers.
5. Use `templates/HANDOFF.md` when available.
6. Tailor the handoff label to the project: `UNUO-HANDOFF`, `UKNOW-HANDOFF`, `GPC-HANDOFF`, or `PROJECT-HANDOFF`.
7. Verify every referenced local path or remote URL before finalizing.
