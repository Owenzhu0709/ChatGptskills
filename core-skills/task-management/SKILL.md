# Task Management

1. Restate the approved objective and non-goals.
2. Break work into independently verifiable blocks with one concrete outcome each.
3. Record dependencies, owner, status, evidence required, and stop condition.
4. Keep only one local execution block active per agent unless parallel work was explicitly requested.
5. Mark work complete only after its evidence exists and is checked.
6. Update the handoff and decision log when ownership or a material decision changes.
