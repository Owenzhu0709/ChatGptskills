# PUA、心理压制与控制：识别和防御

本模块吸收公开关系教练、社交策略和“暗黑心理”资料中的风险分类，但只用于识别、记录、设边界和求助。它不会把对方的拒绝解释成策略，也不会输出实施操控的步骤、模板或阈值。

## 风险分类

| 行为模式 | 可观察信号 | 防御动作 |
| --- | --- | --- |
| 过度理想化/快速绑定 | 刚认识就承诺未来、要求排他、把强烈情绪当亲密证据 | 放慢节奏，保留独立生活和外部支持 |
| 间歇性强化 | 忽冷忽热、失联后突然奖励、用不确定性让你持续等待 | 记录事件而非追逐高点，设置自己的联系和投入上限 |
| 贬低/推拉/羞辱 | 先夸后贬、拿外貌和价值开玩笑、把受伤说成你太敏感 | 直接指出行为和影响；重复发生就减少接触或退出 |
| 煤气灯/现实扭曲 | 否认已发生的事、改写原话、逼你怀疑记忆 | 保存原始记录，找可信的人核对，不在争论中证明自我价值 |
| “测试”与服从阶梯 | 用小请求观察服从，再逐步扩大；把不配合说成不够爱 | 任何一步都可以拒绝；把边界当作信息而非考试 |
| 嫉妒与三角关系 | 故意展示替代对象、比较、制造竞争和紧迫感 | 不参加竞争，要求直接沟通；必要时结束互动 |
| 孤立和监控 | 要求密码、定位、查手机、限制朋友和家人 | 不交出凭证；联系外部支持，评估安全和退出计划 |
| 财务或身份控制 | 借钱、共同账户、工作/签证/住处要挟 | 分开财务和证件，保留文件，咨询当地专业支持 |
| 性压迫 | 以关系、酒精、礼物、沉默或报复施压 | 明确“现在不愿意”即可停止；离开危险现场并求助 |

## 识别报告

```text
风险等级：低/中/高/即时危险
可观察事实：原话、时间、频率、是否重复
可能影响：羞耻、混乱、孤立、依赖、恐惧或财务/身体风险
边界句：我不接受这件事；如果继续，我会结束对话/离开/寻求帮助。
下一步：保存证据、告诉可信的人、减少单独接触、联系当地支持
```

## 把“控制需求”改成健康目标

- “让 TA 离不开我” → 建立透明、互惠、可选择的关系；
- “让 TA 服从” → 清楚表达需求并接受对方不同意；
- “怎么突破拒绝” → 判断拒绝是否明确，并尊重停止；
- “怎么让对方内疚” → 说出影响和边界，不制造羞耻；
- “怎么监控忠诚” → 讨论可接受的承诺和退出条件，不查密码或定位。

## 对用户自身的保护

当用户说“我只是想研究”但要求可复制的压迫脚本时，说明可以提供机制解释和防御演练，不能提供执行方法。若材料来自当前关系，先询问是否安全、是否有报复风险，再决定是否建议对质；有恐惧、跟踪、暴力或强迫时，不要求用户当面对质。
