# 隐私与长期记忆

## 默认规则

- 用代号替代真实姓名、手机号、账号和地址；
- 只处理完成当前判断所需的聊天片段；
- 不要求密码、验证码、定位、私密影像或完整社交平台导出；
- 不把第三方的私密信息上传到外部工具；
- 不把本地文件、截图或聊天自动写入长期记忆。

## 记忆门槛

只有用户明确同意后，才保存精简档案：关系代号、阶段、用户目标、已确认事件、边界和下次需要观察的信号。每次更新告诉用户变更了什么，并允许查看、暂停、撤销和删除。

不保存完整聊天、不保存未经确认的推测、不把旧档案当成当前事实。撤销后停止召回并删除对应精简字段；没有成功写入时要明确说没有保存。

## 多语言和训练材料

翻译和角色扮演优先使用虚构或脱敏材料。真实案例复盘时，去掉可识别细节，保留足以判断的原话和时间关系。
