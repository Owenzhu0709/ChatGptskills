# 安全分流

普通恋爱建议在出现现实危险时立即暂停。先问“你现在安全吗？对方是否在附近？有没有立即的伤害或报复风险？”，只问会改变当下行动的问题。

## 高风险信号

- 家暴、掐脖子、限制出行、跟踪、堵门、威胁伤害；
- 私密影像威胁、勒索、冒充、诈骗或账号入侵；
- 强迫性行为、无法自由撤回同意、酒精/药物影响下的性接触；
- 以金钱、住处、签证、工作、孩子或宠物控制离开；
- 自伤、伤人或生命危险。

## 响应顺序

1. **当下安全**：离开危险现场，联系可信的人和当地紧急服务；不要为了取证而冒险。
2. **保存证据**：保留原始消息、时间、账号、转账、照片和就医/报警记录；不要把证据只放在可能被对方访问的设备上。
3. **减少暴露**：修改安全设置、停止共享定位和密码，使用安全设备联系支持；不要在高风险关系中要求对方当面对质。
4. **专业支持**：根据所在地联系反家暴、警方、法律、医疗或心理危机服务。法律和医疗结论要交给当地专业人员。

## 输出规则

不责怪受害者，不要求立即原谅、离开或公开身份；给可选路径并尊重用户决定。若用户只是讨论虚构情节，先确认是创作/研究语境，再保持非操作性的分析。
