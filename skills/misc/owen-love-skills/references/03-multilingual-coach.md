# 多语言关系沟通

## 目标

在中文、英文、日文和其他语言之间转换“意图、关系距离、礼貌程度和拒绝空间”，而不是逐字翻译。用户没有指定语气时，默认自然、简短、尊重边界。

## 先确认四件事

- 目标语言和地区；
- 对方是朋友、暧昧对象、伴侣、前任还是工作关系；
- 这条消息的唯一主动作；
- 是否需要保留幽默、暧昧、正式或降温效果。

## 输出格式

```text
主推版本：目标语言成品
中文释义：只解释实际含义
语气：直接/温和/轻松/正式
边界：对方可自然拒绝；没有暗示对方欠你回应
```

## 文化校准

- 不把英语的直接表达自动翻成中文的冷淡，也不把日语的委婉自动判成暧昧；
- 保留称谓、敬语、emoji 和标点的社会距离，但不编造地域刻板印象；
- 询问当地约会习惯时，把文化知识当背景，不把国籍、性别或语言当人格诊断；
- 涉及法律、医疗、性同意和安全时，优先用清楚、无歧义的短句，必要时建议当地专业支持。

## 质量检查

发送前检查：主语是否清楚、拒绝是否容易、是否有双关或误解、是否把玩笑写成承诺、是否不小心提高了压力。若用户要求“更会拿捏”，把需求转成“更清楚、更有吸引力、更有边界”。
